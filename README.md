# ZabbixWidgets

Custom Zabbix widgets and their supporting templates and installation documentation.

## Projects

- [Proxmox Backup Server Dashboard](pbs/) — five PBS task and datastore widgets, an extended Zabbix 7.4 template, collectors, and installation tooling.
- [UniFi Network Topology](unifi-network/) — a read-only UniFi topology widget with Zabbix problem overlays, manual topology additions, and a Zabbix 7.4 collection template.
